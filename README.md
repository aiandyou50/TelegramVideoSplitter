# 🎬 동영상 분할기 (Video Splitter)

텔레그램 동영상 업로드를 위한 **무손실 동영상 분할 프로그램**입니다.

## 📌 개요

텔레그램에서 동영상을 업로드할 때 **4GB의 파일 크기 제한**으로 인해 용량이 큰 동영상은 분할이 필요합니다. 이 프로젝트는 다음과 같은 특징을 제공합니다:

- ✅ **무손실 분할**: FFmpeg의 스트림 복사 기능으로 화질 손상 없이 분할
- ✅ **자동 의존성 설치**: 필요한 패키지를 자동으로 감지하고 설치
- ✅ **사용자 친화적 GUI**: Apple 스타일의 세련된 인터페이스
- ✅ **실시간 진행률 추적**: 분할 작업의 진행 상황을 실시간으로 표시
- ✅ **테마 지원**: 시스템, 라이트, 다크 모드 자동 전환
- ✅ **다양한 비디오 포맷 지원**: MP4, MOV, MKV, M4V, AVI, WebM 등

## 📖 사용 방법

### 기본 동작 흐름

1. **동영상 파일 선택**
   - "파일 선택..." 버튼을 클릭하여 분할할 동영상 파일을 선택합니다.
   - 지원 포맷: MP4, MOV, MKV, M4V, AVI, WebM 등
   - 파일 정보(용량, 재생시간, 해상도)가 자동으로 표시됩니다.

2. **저장 위치 설정**
   - 기본값: 원본 동영상과 동일한 위치
   - "변경..." 버튼으로 다른 폴더를 선택할 수 있습니다.
   - "폴더 열기" 버튼으로 저장 폴더를 확인합니다.

3. **분할 용량 설정**
   - **프리셋 옵션**: 200 MB, 500 MB, 1 GB, 2 GB 중 선택
   - **직접 입력**: 원하는 용량을 입력하고 단위(MB/GB) 선택
   - 선택 후 **예상 분할 조각 수**가 자동으로 계산됩니다.

4. **분할 시작**
   - "동영상 분할 시작" 버튼을 클릭합니다.
   - 진행률 바와 상태 메시지를 통해 실시간 진행 상황을 확인합니다.
   - 분할 완료 후 결과 폴더를 자동으로 열 수 있습니다.

### 🎯 예시 시나리오

**상황**: 8GB 크기의 동영상을 텔레그램에 업로드하려면?

1. 동영상 파일 선택 → 8GB 감지
2. 분할 용량 프리셋에서 **"2 GB"** 선택
3. 예상 분할 결과: **약 4개 파일로 분할**
4. "동영상 분할 시작" 버튼 클릭 → 분할 진행 중...
5. 완료 후 4개의 2GB 파일(각각 <4GB)이 생성
6. 각 파일을 텔레그램에 업로드 가능

## 🎨 기능 상세

### 무손실 스트림 복사 (Lossless Stream Copy)

```
FFmpeg 명령어: ffmpeg -i input.mp4 -c copy -map 0 -f segment -segment_time <duration> output_%03d.mp4
```

- **`-c copy`**: 비디오/오디오 재인코딩 없음 → 화질 손상 없음, 매우 빠름
- **`-map 0`**: 모든 비디오, 오디오(다국어), 자막 스트림 보존
- **`-segment_time`**: 동적 계산된 세그먼트 길이로 목표 용량 달성

### 자동 의존성 관리

프로그램 시작 시:
1. **미설치 패키지 검사**: 4개 필수 패키지 확인
2. **자동 설치**: 미설치 패키지 즉시 설치
3. **자동 업데이트**: 매 실행마다 최신 버전으로 업데이트 (오프라인 상태에서는 기존 버전 유지)

### VS Code 자동 설정

VS Code에서 실행 시 `.vscode/settings.json` 자동 생성:
- Python 인터프리터 경로 자동 설정
- 라이브러리 경로 추가 → 임포트 오류 방지

### 실시간 진행 상황 추적

FFmpeg의 stderr 출력을 실시간으로 파싱:
```
time=00:15:30.45 → 진행률 계산 및 표시
```

## 🐛 트러블슈팅

### Q: "imageio-ffmpeg 설치 실패" 에러가 나옵니다.

**A**: 네트워크 연결을 확인하고 다시 프로그램을 실행하세요. 또는 수동 설치:
```bash
pip install imageio-ffmpeg
```

### Q: FFmpeg를 찾을 수 없다는 에러가 발생합니다.

**A**: `imageio-ffmpeg`이 제대로 설치되었는지 확인:
```bash
python -c "import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())"
```

### Q: 분할된 파일이 재생되지 않습니다.

**A**: 
- 파일 포맷이 호환되는지 확인 (MP4, MOV 권장)
- 플레이어가 분할 파일을 지원하는지 확인 (VLC 권장)

### Q: 텔레그램에서 여전히 4GB 제한이라고 합니다.

**A**:
- 분할된 각 파일이 **4GB 미만**인지 확인하세요.
- 안전을 위해 3.5GB 이하로 분할을 권장합니다.
